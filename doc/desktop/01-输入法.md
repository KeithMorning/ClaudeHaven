# 输入法（fcitx5 + Rime 万象）

> 结论先行：输入法链路走了 IBus → lxterminal → fcitx5 多轮演进，最终方案是
> **fcitx5 换壳 + Rime 万象引擎不换**。踩坑实录按编号集中在
> [pitfalls/03-输入法.md](../pitfalls/03-输入法.md)，本页只讲当前机制与用法。

## 当前链路

```
按键 → X server → lxterminal/Chrome (GTK3 im module) → fcitx5 → Rime → 中文提交
```

- 输入法放进 VM 内部，绕开 **WSLg 只转发按键、不转发 Windows IME preedit 组合串**的协议限制
- **fcitx5**（国内 Linux 桌面事实标准）：面板跟手、横排候选、字体正常
- **引擎 Rime + 万象拼音 Pure 词库**（`amzxyz/rime_wanxiang` v18.1.8，CC BY 4.0）：简体拼音整句
- v18 用 **ccache** 替代旧 `build/`，默认 8 线程编译；词库 zip 26 MB 离线随包，不依赖首次启用时 GitHub 可达
- 用户目录 `~/.local/share/fcitx5/rime`，profile 写 `DefaultIM=rime`
- 字体按需装：fcitx5 + frontend-gtk3 + HanaMin（CJK 扩展 B 区字形）
- 相关组件由 `rime-setup.sh` 按需安装，`--no-install-recommends` 保证零字体依赖、不碰 checkcc 名单

## 快捷键

| 键 | 作用 |
| --- | --- |
| `Ctrl+Space` | 输入法开关（state 1↔2） |
| `Shift` | 中英切换（Rime 内） |
| `Win+Space` | 输入法开关；Windows 宿主可能拦截此组合键 |
| `Ctrl+Shift` | 切换引擎 |

## 为什么最终是 fcitx5

1.0.26~1.0.33 用 IBus/Rime，面板在 VNC 里钉在左下角、竖排旧样式、字体豆腐块 ——
这是**壳**的问题，Rime 引擎与万象词库一直没问题。换 fcitx5 只换壳、词库全复用。
完整取舍见[输入法演进](../decisions/02-输入法演进.md)。

## 四个隐蔽陷阱（历史坑，勿重踩）

1. **guard 误杀**：`desktop-guard.sh` 必须等 D-Bus 会话总线导出之后再启动，否则
   `fcitx5-remote` 探活永远失败，4 秒一轮杀掉重拉。
2. **激活语义**：进程活着 ≠ 可输入。默认 state=1（关闭，按键透传为 ASCII）；
   必须 `-s rime` 才真正激活到 state=2，`-o` 单独只到 1。重启后发 `-s rime` + `-o`（先 -s 后 -o）。
3. **测试互踩**：Ctrl+Space 是 1↔2 开关、跨实验粘滞；合成打字前先读 state 再决定是否按开关。
4. **零候选时窗口消失**：`ffff` 这类非法编码 → 零候选 → classicui 把候选窗 unmap；
   叠加 client preedit 把编码交给应用画 → 既无候选也无编码，退格全盲。
   修法：写 `/root/.config/fcitx5/config` 的 `[Behavior] PreeditEnabledByDefault=False`，
   让 classicui 自己画编码；同时 `page_size` 保持 6（万象 7890 是声调键，不是选字键）。

以上四条的完整排查过程、复现脚本（`build/ime-repro.sh` 等）见[坑 17~20](../pitfalls/03-输入法.md)。

## 验证边界

xdotool（XTEST）合成的按键能进 pty 但**不触发 XIM/输入法的组合**，所以自动化只能推到
「IM 模块加载 + 引擎激活 + 按键送达」，**最后一步必须真人按一次**确认。这条误判曾浪费多轮
（见[坑 11](../pitfalls/03-输入法.md)）。

## 同步注意

脚本只有一个真源 `claude-vm/vm/scripts/`。改了 `rime-setup.sh` 要同步
`runtime/scripts/` → 已安装应用 `resources/scripts/` → VM `/opt/scripts/`，并在 VM 内直接执行
一次写配置。少任何一层都会回到「修复在包里、不在环境里」。详见
[坑 13](../pitfalls/01-脚本同步与假活.md)。
