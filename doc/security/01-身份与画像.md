# 身份与画像

> 目标：环境自洽、真实度高，而不是「伪装度高」。
> 核心认知：**挂 VPN 出境是全球用户日常，出口 IP 不必和时区同地区** ——
> 风控抓的是「是不是中国时区 / `zh-CN` / 名单内字体」，不是「时区和 IP 国家是否匹配」。

## 独立身份只生成一次

- WSL 继承宿主计算机名（如 `HomeVisionPC`），`/var/lib/dbus/machine-id` 来自 Docker 模板、
  所有安装相同。entrypoint 生成 `DESKTOP-XXXXXXX` + 新 machine-id，写进 `/opt/config/identity`，
  之后复用。
- **每次启动都换反而更像新机器，别做。**
- 但 WSL 每次会话重启会把 `/etc/hostname` 重设成宿主名，所以每次启动都要重新套用 identity。
  自检那条「环境身份不一致」warn 实际是**会话已退出**的信号，不是身份逻辑坏了。
- 一键重置会彻底重生成身份，见[环境重置](02-一键环境重置.md)。

## 画像三端对齐

默认画像：**中国台湾地区·台北的用户挂 VPN**

| 维度 | 值 |
| --- | --- |
| 时区 | `Asia/Taipei`（UTC+8） |
| locale | `zh_TW.UTF-8`（entrypoint 现场 locale-gen，一次生成持久保留） |
| Chrome 语言 | `zh-TW`，`intl.accept_languages` 正确值 `zh-TW,zh,en-US,en` |
| 输入法 | fcitx5 + Rime 万象拼音（简体拼音整句） |

**别把「画像对齐」做成新的伪造痕迹**（坑 10）：

- `intl.accept_languages` 是纯语言标签列表，q 权重由 Chrome 自己生成。手写 `;q=0.9` 会发出
  重复 q 的畸形头，比默认 `en-US` 更像伪造。改完必须**真发一次请求量头**。
- `--lang` 只改 UI 语言、不重写已有 Profile；`chrome-login.sh` 与 entrypoint 都要调
  `chrome-lang.py --set`。
- DNS：走 HTTP 代理的 HTTPS 是 CONNECT 远程解析，本地 `getent` 不参与。**别改 nameserver**，
  要清的是 WSL 继承的 `search ljstaff.com` 企业域后缀。
- 自检**不得**按时区反推期望国家然后判 fail —— 会误杀所有挂 VPN 的合法用户；已改为只拦
  出口落在 CN/HK/MO，「出口类型」标 warn 对齐检测站口径。

## 字体与指纹

- `Noto Sans TC` 与被点名的 `Noto Sans CJK TC` / `PingFang TC` / `Source Han Sans TC`
  是**不同家族名**（`fc-scan` 实测），装它不扣分。
- CJK 扩展 B 区补 `fonts-hanazono`（家族名「花園明朝」不在 checkcc 名单），
  **不能用 `fonts-noto-cjk-extra`**（214 MB 且家族名直接命中名单扣分）。
- 字体链：`vm/assets/fonts → runtime/assets/fonts → /opt/assets/fonts →
  /usr/share/fonts/truetype/claude-{sc,tc}`，别只放一边。
- 词库 CC BY 4.0，包内保留署名。
