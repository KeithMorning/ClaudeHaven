# 项目概览

> 一句话：在 Windows 上一键拉起隔离的 Linux 桌面环境，预装 Chrome 与 Claude Code，
> 强制所有出网流量经代理（fail-closed：代理断开即断网，不回落直连）。

**打包时间**：2026-11-16　｜　**应用版本**：1.0.37　｜　**源码体积**：约 44 MB（含 26 MB 万象词库 + 29 MB 中文字体）

## 两个工程

| 目录 | 是什么 |
| --- | --- |
| `claude-desktop/` | Electron 桌面程序（主进程 / 渲染层 / 双显示模式 / 打包配置） |
| `claude-vm/` | Linux 运行时环境（Dockerfile、entrypoint、桌面布局、自检脚本） |

> `claude-vm/` 里**没有** rootfs 镜像（约 650 MB），需按[环境与启动](01-环境与启动.md)单独获取。

## 本次版本的设计方向（先看，避免走错路）

**1.0.21 起主路径是 WSLg 独立窗口**，不再是浏览器串流：

```
Electron 应用（设置 / 自检 / 状态）
   └─ wsl -d claude-vm → entrypoint.sh
        ├─ DISPLAY_MODE=wslg    → 直接输出到 :0，Windows 上就是独立原生窗口
        └─ DISPLAY_MODE=desktop → Xvnc + noVNC:6080，<webview> 内嵌（可选，Mac 兜底）
```

选 WSLg 的原因：noVNC 是「把桌面编码成图片再传回来」，清晰度取决于带宽和 JPEG 质量，
中文输入与快捷键始终隔一层；WSLg 是系统自带的 Wayland/X 转发，窗口是 Windows 真实窗口，
剪贴板由系统原生桥接，体验接近本机。取舍详见[显示模式选型](../decisions/01-显示模式选型.md)。

**登录授权仍在虚拟机里完成**：WSLg 下点「登录 claude.ai」弹出容器内 Chrome 窗口，
登录态落在容器 `~/.config`，之后 `claude` 直接复用，不再开浏览器。

**1.0.22 起网络 fail-closed**：`HTTP_PROXY` 只是应用层建议，不读环境变量的程序、DNS、
raw socket 都能绕过。现在 entrypoint 在业务启动**之前**用 netlink 删默认路由、关 IPv6，
让代理成为唯一出口。详见[网络熔断](../network/01-网络熔断.md)与[坑 8](../pitfalls/02-网络与代理.md)。

**1.0.23 起画像改为「中国台湾地区·台北的用户挂 VPN」**（默认）：
`Asia/Taipei`（UTC+8）+ `zh_TW.UTF-8` + Chrome `zh-TW` + Rime 输入。
关键认知：**挂 VPN 出境是全球用户日常，出口 IP 不必和时区同地区** —— 风控抓的是
「是不是中国时区 / `zh-CN` / 名单内字体」，不是「时区和 IP 国家是否匹配」。
实测切到台北后四项地区检测全绿、checkcc 仍 41 分。详见[身份与画像](../security/01-身份与画像.md)。

**1.0.24 把 Rime 方案换成万象拼音 Pure 词库**（`amzxyz/rime_wanxiang` v18.1.8，CC BY 4.0）：
台湾注音是大千式键盘，习惯拼音的用户几乎打不了字；万象是简体拼音整句词库。
**对检测评分零影响**（检测站看不到输入法与聊天内容）。代价是体积与首次编译约 1 分钟。
详见[输入法](../desktop/01-输入法.md)。

## 当前已知的功能边界

两种模式共通：网络强制经代理（`NET_GUARD=strict` 默认）。代理断开时网络内核层面直接不通；
出口地区异常 / 多源出口分叉时预检拦截并保持断网；界面状态条与自检面板显示原因。
可在设置里切 `off` 关闭（不推荐）。完整边界见[已知边界](../security/03-已知边界.md)。
