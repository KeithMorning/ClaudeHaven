## 环境要求

- **Windows 11，或 Windows 10 19044+ 且使用商店版 WSL**（WSLg 的前置条件）
  - 更老的 Win10（2004/21H1 等内置版 WSL）**没有 WSLg**，只能用 `desktop` 模式走 noVNC
- BIOS 已开虚拟化（WSL2 前提）
- Node.js 18+（当前依赖 electron 45 / electron-builder 26）
- 想重建镜像才需要 WSL2 + Docker Desktop；只改界面不需要
- macOS 见[平台 · macOS 容器后端](../platform/02-macOS-容器后端.md)

## 先拿到运行时镜像（不重建也能跑）

应用启动时把 `runtime/rootfs.tar.gz` 导入为 WSL 发行版 `claude-vm`。
**这个文件不在源码包里**，二选一：

```bash
# 方式 A：从旧机器直接拷（推荐，保证环境完全一致）
#   把旧机器的 claude-desktop/runtime/rootfs.tar.gz 放到新机器同一位置

# 方式 B：从 Dockerfile 重建（产物可能与旧机器有细微差异）
wsl -d Ubuntu-22.04 -u root -e bash -lc \
  "bash /mnt/<盘符>/<路径>/claude-desktop/scripts/build-rootfs.sh"
```

放到 `claude-desktop/runtime/rootfs.tar.gz` 即可。`runtime/` 下其余内容（`scripts/`、`assets/`）
会在 `npm start` 前由 `sync-scripts` 自动生成，**不要手工维护**（见[坑 1](../pitfalls/01-脚本同步与假活.md)）。

无 Docker 环境下的 1.0.37 增量重建方案见[构建与打包](../engineering/01-构建与打包.md)。

## 跑起来

```bash
cd claude-desktop
npm config set registry https://registry.npmmirror.com
set ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/
set ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/
npm install

npm start             # 开发运行（会先自动 sync-scripts）
npm run dist:win      # 只出 NSIS 安装包（约 740 MB）
npm run dist:portable # 需要便携版时才跑
```

首次导入 rootfs 需要 1~3 分钟；之后 wslg 模式约 5~10 秒，desktop 模式约 10~20 秒（等 noVNC 起）。

> ⚠️ 1.0.37 起镜像内含随包 mihomo 内核与 GeoIP 数据库。若用了 1.0.36 及之前的旧 rootfs，
> TUN 模式会因缺内核/数据库而保持全断网；**必须重建 rootfs**，见[构建与打包](../engineering/01-构建与打包.md)。

## 两种显示模式怎么选

| 场景 | 选哪个 |
| --- | --- |
| Win11 / 新版 Win10，要原生窗口、系统剪贴板 | `wslg`（默认，推荐） |
| 老 Win10 无 WSLg、远程桌面、Mac 兜底 | `desktop`（noVNC 串流） |

逐项差异见[显示模式](../desktop/02-显示模式.md)。
