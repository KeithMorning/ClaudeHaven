## 4) 别删除 `@anthropic-ai/claude-code/.../bin/claude.exe`。

它是 **245 MB 的原生 ELF 二进制**，后缀是 `.exe` 但不是 Windows 文件。
历史上一条 `find -name '*.exe' -delete` 把它删了，导致 `claude` 直接不可用。
Claude Code 自更新中断也会把整包换成「500 字节报错桩 + 43 MB 残片」，entrypoint 每次启动会自检并重建链接。

## 10) 1.0.25：别把「画像对齐」做成新的伪造痕迹。

- Chrome 的 `intl.accept_languages` 是**纯语言标签列表**，q 权重由 Chrome 自己生成。
  第一版写成 `zh-TW,zh;q=0.9,...`，headless 实测发出
  `zh-TW,zh;q=0.9,zh;q=0.9;q=0.8,...` 这种重复 q 的畸形头，比原来的 `en-US` 更像伪造。
  正确值是 `zh-TW,zh,en-US,en`。**改完必须真的发一次请求量头**，只读配置项看不出这个错。
- `--lang` 只改 UI 语言，不重写已有 Profile；`chrome-login.sh` 与 entrypoint 都要调
  `chrome-lang.py --set`，否则用户没点过登录页时配置不会生效。
- DNS 预演结论：走 HTTP 代理的 HTTPS 是 CONNECT 远程解析，本地 `getent` 结果不参与；
  熔断后本地给的内网黑洞（`10.36.28.73`）直连不可达。**别改 nameserver**，也别把
  「本地解析到内网」报成 warn。真正要清的是 WSL 继承的 `search ljstaff.com` 企业域后缀。
- 自检里曾有 `_expected_cc()` 按时区反推期望国家、不匹配就判 fail 并建议改地区 ——
  这条会误杀所有挂 VPN 的合法用户，且映射表漏了 `Asia/Taipei`，导致默认台北画像下整项被静默跳过。
  已删除，改为只拦出口落在 CN/HK/MO；「出口类型」也从 pass 改成 warn，对齐检测站口径。
- `chrome-lang.py --shell` 输出 4 行供 bash `mapfile` 读取，别用 `eval`。
  headless 用独立 `--user-data-dir` 并复制真实 Profile，测到的才是登录时真正发出的头。

## 21) 一键重置必须是「先停会话，再销毁磁盘」。

`stopRuntime()` 只是 `--terminate` / `docker stop`，数据全留着，换不掉身份。
重置要 `--unregister` + 清 vhdx 残留（WSL）/ `docker rm -f` + 删 home 卷（容器），
并清宿主 `last-start.json` 指纹。顺序反了，运行中的 Claude Code 退出时会把内存
里的旧登录态写回 `~/.claude`，等于白清。界面必须两段式确认。
