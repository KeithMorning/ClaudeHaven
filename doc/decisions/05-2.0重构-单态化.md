# 决策：2.0 重新设计 —— 删冗余、单态化

> 用户 2026-11-16 提出：「重新设计这个 APP，删除冗余的功能」，并定了四条。
> 这是 1.0.x 之后第一次**做减法**的版本。

## 四条决策

| # | 决策 | 用户选择 |
| --- | --- | --- |
| 1 | 删除外部代理，只保留容器内 mihomo + TUN 全量接管；导入 YAML 后支持选择节点 | **全量单节点**：所有流量走选中节点，忽略订阅原有 `proxy-groups` / `rules` |
| 2 | 不再支持 wslg 模式 | 只保留 desktop 串流桌面 |
| 3 | 增加伪装用户功能（台北 / 美国人环境） | **只做两套**预设卡片，不做硬件/浏览器指纹伪造 |
| 4 | 提供单独检查报告 | **独立 BrowserWindow**，主窗口桌面不遮挡、可导出 HTML |

本轮交付范围：**代码 + 全量测试**；rootfs 重建与安装包留到下一轮。

## 为什么是全量单节点

旧链路有两套并存：`UPSTREAM_PROXY` 显式代理（含白名单 router）与 `TUN_MODE` 开关。
并存本身成了维护负担，也让「宿主代理软件运行中切 Direct → 界面假绿」这个盲点一直存在。

单态化后：
```
应用（无 -x / 无 HTTP_PROXY / Chrome 无 --proxy-server）
  → TUN Meta（table 2022 覆盖路由）
  → 容器内 mihomo（DNS 127.0.0.1:53、fake-ip 198.19.x）
  → YAML 里用户选中的那一个节点
  → eth0 on-link（net-guard 保留的唯一通路）
```
宿主 Clash 只负责编辑/导入订阅，**完全退出运行时链路**。这样「要不要关 Clash」
「宿主 fake-ip 污染」「切 Direct 假绿」一次性全消失。

用户选「全量单节点」而不是「保留订阅分流」，是因为目标窄（编码环境）：
少一组规则就少一组可能配错的规则，且不存在国内网站要走直连的需求。

## 为什么只做两套画像

现有 `region` 下拉有 7 个地区，但散落在 `renderer.js` 的 `REGIONS` 常量、
`chrome-lang.py` 的 `LANGS` 表、以及 `entrypoint` 的 locale 生成里，容易分叉。
2.0 收敛成 `app/lib/personas.js` 单一真源，只有两套：

| id | tz | lang | chromeLang |
| --- | --- | --- | --- |
| `tw-taipei` | `Asia/Taipei` | `zh_TW.UTF-8` | `zh-TW` |
| `us` | `America/New_York` | `en_US.UTF-8` | `en-US` |

**不做** Canvas/WebGL/音频假噪音、随机指纹、UA/分辨率伪造 —— 防封教程里
明确要求「关掉假噪音」，开假噪音反而一眼被识破。身份（hostname / machine-id）
仍只生成一次，切画像不重置，避免「像一台新机器」。

## 为什么报告要独立窗口

旧自检是主窗口里的 `#checkPanel.cp-mask` 全屏遮罩。`<webview>` 是独立图层，
CSS z-index 盖不住它，所以打开面板时必须把 webview 收起来 —— 桌面画面直接消失。
用户说「检查报告是单独页面，不影响使用」，正是指这个。

2.0 用新 `BrowserWindow` 加载 `report.html`，主窗口的串流画面从头到尾不动。
报告本身只读（`check-env.sh --json`），不改变运行时状态，也不阻塞启动。
额外加了「导出 HTML 报告」，把排好的版面落成可独立打开的文件。

**主进程** `app/main.js`：1358 → 866 行。删掉

`persona / selectedNode / clashYamlPath`。

## 后续修订（2.0.3）

- **画像固定为台北 / 洛杉矶两套**（原美区为纽约）。明确**不做「按出口 IP 自动对齐画像」**：
  真实出口只有 mihomo 起来后才探测得到，而 `TZ/LANG` 在会话启动那一刻定死、
  运行中改不动；自动对齐要么改成两阶段启动（先起内核探测再拉桌面），要么只能下次
  启动生效，都会引入复杂度与「启动→探测→改画像→重建」的循环风险。
  用户按所选节点的落地地区手动挑画像即可。
- **浏览器语言收归画像单一真源** `CHROME_LANG`：修复 `chromeLang` 死字段、四处各自猜语言、
  `intl.app_locale` 未写入、旧 Chrome 实例忽略 `--lang` 导致的「报告全绿、实际繁中」。
  详见 `doc/log.md` 坑 25。
- **新增节点延迟展示**：`tun-merge.py` 生成仅监听客机回环的 `external-controller`，
  `node-delay.py` 实测各节点往返延迟，界面下拉与检查报告都展示。控制 API 不暴露到宿主，
  也不改变 fail-closed 网络模型。
